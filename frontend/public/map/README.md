# Offline map assets

The sprites and glyphs the Protomaps basemap style needs, copied from
https://github.com/protomaps/basemaps-assets (sprites v4 `light` and `dark`; the Noto Sans
Regular, Medium and Italic glyph ranges for Latin, Greek, Cyrillic and general punctuation,
`OFL.txt` is their licence). They ship inside Field so the map draws without a connection;
a script with no glyphs here shows no label. The tiles themselves come from the Protect server
as a PMTiles extract of the project's area (Field's decision D4), OpenStreetMap data under the
ODbL, built by Protomaps.
