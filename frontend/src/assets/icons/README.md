# Icon assets

`lora_gateway.svg` is the icon Protect draws an offload station with (its entity type's icon
`device.lora_gateway`), taken from Protect's icon registry, which took it from the open source
EarthRanger server (https://github.com/PADAS/er-server, Apache License 2.0, the licence in
`LICENSE-EarthRanger`). A square `viewBox` with `fill="currentColor"` and nothing baked in,
as Protect's registry demands. `components/icons/markers.ts` draws it the way Protect's
`markers.ts` does.
